Apa output dari kode berikut?

const greet = name => "Hello, " + name + "!";

console.log(greet("Bob"));

Pilihan Jawaban:

Penjelasan:

Kode tersebut menggunakan arrow function versi ringkas yang langsung mengembalikan nilai.

Saat greet("Bob") dipanggil, parameter name diisi dengan string "Bob".

Fungsi menggabungkan "Hello, " + "Bob" + "!", sehingga menghasilkan:

Hello, Bob!
