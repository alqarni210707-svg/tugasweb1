Apa yang terjadi jika fungsi tidak memiliki return statement?

PILIH DUA JAWABAN YANG BENAR!

function noReturn() {
    let name = "Bob";
}

let result = noReturn();

console.log(result);

Penjelasan:

Jika sebuah fungsi tidak memiliki return statement, JavaScript secara otomatis akan mengembalikan nilai undefined.

Karena fungsi noReturn() tidak memiliki return, maka nilai yang dikembalikan adalah undefined.

Variabel result menampung nilai tersebut, sehingga result juga berisi undefined.

Jawaban yang benar:

✓ Opsi 1. result akan berisi undefined.

✓ Opsi 4. Fungsi akan mengembalikan undefined secara implisit.

Output Program:

undefined
